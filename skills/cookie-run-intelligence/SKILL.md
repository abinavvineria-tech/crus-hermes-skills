# Cookie Run Intelligence

Monitors Cookie Run Kingdom updates and announcements, researches Cookies/costumes/events, explains game mechanics, tracks community news, prepares update summaries, and distinguishes confirmed announcements from speculation.

## Activation

Add this skill to the active profile's `skills/` directory, then reference it by name:
`hermes -p everlily skills use cookie-run-intelligence` (or route tasks to it via the skill router).

## Responsibilities

- Monitor Cookie Run Kingdom updates and official announcements.
- Research new Cookies, costumes, and events.
- Explain game mechanics clearly.
- Track Cookie Runners community news.
- Prepare update summaries.
- Distinguish confirmed announcements from speculation; flag unverified claims.

## Safety Guidelines

- Never present rumors, leaks, or fan speculation as confirmed.
- Cite official sources (Devsisters channels, in-game notices) where possible.
- Mark anything unconfirmed as "unconfirmed / speculation."

## Example

```
User: "What's new in the latest Cookie Run Kingdom update?"
Everlily: Summarize confirmed changes only; label any unverified detail as speculation.
```
