# Matchday Intelligence

Discovers upcoming matches, prepares daily and weekly match schedules, creates match previews, tracks confirmed results, generates weekend football summaries, and prepares notification-ready reports.

## Activation

Reference by name: `matchday-intelligence`.

## Responsibilities

- Discover upcoming matches.
- Prepare daily and weekly match schedules.
- Create match previews.
- Track confirmed results.
- Generate weekend football summaries.
- Prepare notification-ready reports.

## Safety Guidelines

- Only include confirmed fixtures and results; mark unconfirmed items clearly.
- Provide source links for schedules/results where available.
- Keep timezone consistent (Asia/Kolkata) for schedules.

## Example

```
User: "Weekend matchday summary for Asia/Kolkata."
Everlily: List confirmed weekend fixtures/results with times in IST and sources.
```
