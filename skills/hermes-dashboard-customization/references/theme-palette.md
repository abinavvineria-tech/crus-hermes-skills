# Cookie Run Studio Theme Palette

Dark fantasy theme built for Captain Abinav's Cookie Runners United (CRU) at United Stadium.

## Palette

| Layer | Hex | Role |
|-------|-----|------|
| background | `#1a0b2e` | Deep royal purple — canvas base |
| midground | `#ffd700` | Gold — primary text + accent |
| foreground | `#f8f4f0` | White Lily cream — top-layer highlight |
| warmGlow | `rgba(74, 144, 226, 0.35)` | Royal blue glow |
